# APK / SDK Information

## APK

This repository does not currently include an Android APK.

Pixie is a web application built with Next.js and is intended to run in a browser or be deployed as a web app. There is no native Android project, Gradle configuration, Android manifest, signed APK, or app bundle in this repository.

If an APK is created later, document the following here:

- APK file name
- App version
- Build type
- Package name
- Signing status
- Minimum Android version
- Target Android version
- Build command
- Release notes

## SDKs and Major Libraries

The project uses JavaScript/TypeScript SDKs and web libraries through `npm`.

Major SDKs and integrations include:

- Next.js: web application framework
- React: UI framework
- Vercel AI SDK: AI chat, streaming, and model integration
- OpenAI SDK: model access and audio transcription
- Anthropic AI SDK provider: Anthropic model access
- Google AI SDK provider: Gemini model access
- Groq SDK / OpenAI-compatible provider: Groq model access
- Supabase SDK: authentication and database access
- Google APIs SDK: Google Calendar OAuth and event access
- ElevenLabs SDK/API: text-to-speech voice output
- Telegram Bot API integration: Telegram linking, replies, and notifications
- TomTom APIs: geocoding, routing, traffic, and commute planning

## Runtime Platform

Pixie runs as a Next.js web app.

Typical runtime:

- Node.js server runtime for API routes
- Browser runtime for the client UI
- Supabase for authentication and persisted app data
- Third-party provider APIs for AI, calendar, maps, voice, and messaging features

## Mobile Support

The app can be opened in a mobile browser, but it is not packaged as a native mobile application.

Mobile-related browser features may include:

- Microphone access for voice input
- Browser speech synthesis for voice output
- Location access for commute planning, when the user grants permission

These features depend on browser permissions, HTTPS availability, and device/browser support.

## Build Commands

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production web app:

```bash
npm run build
```

Start production server:

```bash
npm run start
```

## Notes for Reviewers

- No APK is generated by the current project scripts.
- No Android SDK is required to build this repository.
- All SDK usage is through npm packages listed in `package.json`.
- Environment variables are required for external provider integrations.
